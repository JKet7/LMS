## 4. Локальный сервер (`server.js`)

Node-сервер на порту **3000**, слушает `0.0.0.0` (доступен с телефона в той же Wi-Fi).

### 4.1. Раздача статики

Отдаёт файлы из `ROOT` (папка `server.js`). `/` → **`index.html`**. `Cache-Control: no-cache`.

### 4.2. Сохранение — `POST /save-data`

- Принимает тело (готовый `data.js`).
- Определяет папку курса из `Referer`:
  - `/Test/app.html` → `Test` ✓
  - `/Test/admin.html` → `Test` ✓ (старая ссылка)
- Пишет в `ROOT/Test/data.js`.
- **Валидация:** тело должно содержать `const courseSettings` и `const allLessons`. Иначе — 400.
- Отвечает `200 ok`.
- Лимит тела — 50 МБ.
- Запись — **асинхронная** (`fs.promises.writeFile`).

### 4.3. Загрузка медиа — `POST /upload?course=Test&type=images&filename=foo.png`

- Сохраняет в `ROOT/Test/images/foo.png` (или `videos/`).
- При совпадении имени — добавляет `_1`, `_2`, … (до 1000).
- Возвращает `{ path: "images/foo.png", size: 12345 }`.
- Имя санитизируется: `[^a-zA-Zа-яА-Я0-9._\-\s]` → `_`.
- **Белый список расширений:** `.png .jpg .jpeg .gif .webp .svg .mp4 .webm .ogg`. Остальные — 400.
- Лимит файла — 200 МБ.

### 4.4. Проверка — `GET /ping` → `pong`.

### 4.5. Особенности

- `safeJoin` с `.normalize("NFC")` — корректная работа с кириллицей в путях.
- **`safeJoin` защищает от выхода за ROOT** через проверку `b === a || b.startsWith(a + path.sep)`.
- `decodeURIComponent` в GET обёрнут в `try/catch`.
- Диагностика на старте: `ROOT`, наличие `index.html`, IP-адреса для телефона.

## 5. Формат данных (`data.js`)

```js
const courseSettings = {
    "courseKey": "english",
    "pageTitle": "Английский",
    "courseTitle": "Английский: Артикли"
};

const allLessons = {
    "new_lesson": {
        "type": "theory",
        "title": "Теория",
        "description": "Краткое описание блока",
        "coverImage": "images/cover.png",
        "slides": [ /* ... */ ]
    },
    "new_quiz": { /* ... */ }
};
```

**Новые опциональные поля блока:**
- `description` — краткое описание (показывается в меню при наведении).
- `coverImage` — фоновая картинка блока (в правой панели меню).

`courseKey` — для ключей в `localStorage`. Нет ключа → `"default"`.

### 5.1. Типы блоков (`lesson.type`)

| Тип | Структура |
|---|---|
| `theory` | `{ title, description?, coverImage?, slides: [{ shortName, title, content: [...] }] }` |
| `quiz` | `{ title, description?, coverImage?, groups: [], randomizeQuestions, randomizeOptions, questions: [...] }` |
| `memo` | `{ title, description?, coverImage?, cells: [{ title, content: [...] }] }` (макс. 8) |
| `glossary` | `{ title, description?, coverImage?, terms: [{ name, content: [...] }] }` |

### 5.2. Блоки контента (внутри `content[]`)

| Тип | Структура |
|---|---|
| `p` | `{ type: "p", text, notes? }` — может содержать `<b>`, `<i>`, `<u>`, `<s>`, `<br>`, `style="text-align:..."`, `[[wiki-ссылки]]` и `((N))` примечания. `notes` — массив строк примечаний. |
| `h3` | `{ type: "h3", text, notes? }` |
| `quote` | `{ type: "quote", text, notes? }` |
| `ul` | `{ type: "ul", style: "bullet"\|"number"\|"checkbox", items: [{ text, level: 0\|1\|2 }] }` |
| `link` | `{ type: "link", text, href }` — внутренние `#ключ_блока:слайд` или внешние |
| `image` | `{ type: "image", src, alt, markers? }` — `markers` — массив точек с примечаниями |
| `video` | `{ type: "video", src }` |
| `table` | `{ type: "table", header: bool, rows: [[...]] }` — макс. 10×10 |

### 5.3. Типы вопросов

| Тип | Структура |
|---|---|
| `single` | `{ type, text, options: [], correct: [1], explain, group }` |
| `multi` | `{ type, text, options: [], correct: [N], explain, group }` |
| `match` | `{ type, text, pairs: [{ left, right }], explain, group }` |
| `card` | `{ type, front, frontImage, back, backImage, group }` |

### 5.4. Wiki-ссылки и примечания

**Wiki-ссылки:**
- `[[ключ]]` — ссылка на блок.
- `[[ключ:3]]` — блок + слайд/ячейку/термин №3.
- `[[ключ|текст]]` — с кастомным текстом.
- `[[ключ:3|текст]]` — комбинация.

**Примечания `((N))`** — пояснения к фрагменту текста. Хранятся в `block.notes` — массив строк. Маркер `((1))` привязан к `notes[0]`.

### 5.5. Маркеры на картинке

В `image`-блоке — массив `markers: [{ x, y, text }]`, где `x`, `y` в **процентах** от размера картинки.

- **Клик по заголовку слайда** → inline-редактирование.

## 9. Логика читателя (`reader.js`, режим `reader`)

### 9.1. Экраны

Пять экранов: `menu`, `lesson`, `quiz`, `memo`, `glossary`. Переключение — `showScreen(name)`.

### 9.2. Адаптивная ширина

- `memo` → `.wide`
- `quiz` → `.narrow`
- остальные → обычная

### 9.3. Меню курса

- Двухколоночный `.menu-split`.
- **Слева:** поиск + список.
- **Справа:** preview (заголовок, бейдж, описание, обложка как фон с градиентом).
- **Мышь:** наведение → preview, клик → открыть.
- **Тач:** первый тап → preview, второй по той же строке → открыть.
- **Кнопки:** «Начать» / «Продолжить» / «Сначала» (сброс) / «Открыть».

### 9.4. Теория

- `renderSlide()` — слайд + навигация.
- `renderContentBlocks()` — блоки: `p` → `<div class="text-p">`, `h3`, `quote`, `image` (с маркерами и лайтбоксом), `video`, `table`.
- Прогресс: `markVisited`, `updateProgressBar`, `renderTopicList`.

### 9.5. Безопасный рендер текста

**`renderSafeText(text, opts)`** — экранирует HTML, но **разрешает** теги из белого списка и сохраняет wiki-ссылки.

**Ключевая регулярка:** `/&lt;(\/?)([a-zA-Z][a-zA-Z0-9]*)\b([\s\S]*?)&gt;/g`
> **Важно:** `[\s\S]*?`, а не `[^&]*?`. Второй ломается на атрибутах с `&`.

### 9.6. Wiki-ссылки

`renderWikiLinks(html)` находит `[[...]]` и превращает в `<a class="wiki-link wiki-link-<type>">`.

- Тип блока определяет цвет: `theory` → бордовый, `quiz` → зелёный, `memo` / `glossary` → синий.
- **Backlinks** — `buildBacklinksIndex()` один раз, `renderBacklinks(targetLessonId)` — «↩ Упоминается в».

### 9.7. Примечания `((N))`

`renderNotes(html, notes)` → `<span class="note" data-note-idx="N-1" data-note-text="...">N</span>`.

- Наведение → карточка (`.note-card`).
- Клик / тап → показать / скрыть.
- `((N))` без парного `notes[N-1]` → `.note-broken`.

### 9.8. Маркеры на картинке

`renderImageBlock(b)` → если есть `markers`, рисует `.img-marker` поверх.

- Клик по маркеру:
  - **десктоп** → карточка рядом.
  - **мобильный** → модалка.

### 9.9. Лайтбокс

- Двойной клик / двойной тап → `.lightbox-overlay`.

### 9.10. Тест

- `startQuiz(id)` — фиксация порядка.
- `renderQuiz()` — текущий вопрос.
- Навигация, ответы, результат.
- **Оценка** — с первой попытки.
- **Таймер** — сохранение каждые 10 сек.

### 9.11. Памятка

`renderMemo(lesson)` — сетка `.memo-grid` с колонками 1–4 + навигация.

### 9.12. Глоссарий

Сортировка по имени, буквенные разделители, поиск с подсветкой `<mark>`.

**Экспорт CSV** — кнопка 📊 в шапке.

### 9.13. PDF (печать)

`printCurrent()`:
- **теория** — все слайды блока, каждый с новой страницы.
- **тест** — все вопросы + ответы отдельным блоком.
- **глоссарий** — все термины, сайдбар скрыт.
- **памятка** — все ячейки.

**`prepareNotesForPrint()`** — примечания под каждым блоком; **`cleanupPrintNotes()`** — удаление после печати.

### 9.14. Справка

Модалка с информацией о блоке, датой изменения, backlinks и сносками.

## 10. Логика редактора (`reader.js`, режим `author`)

### 10.1. Тот же интерфейс + инструменты

**Не отдельная админка.** Тот же плеер, но:
- К каждому блоку контента — ручка `⠿`, rich-панель, кнопка `✕`.
- Заголовки редактируются inline.
- В сайдбарах — ⋮ меню и кнопки «＋».

### 10.2. Inline-редактирование

- **Клик по названию блока** в меню → `contentEditable`.
- **Клик по заголовку слайда** → `contentEditable`.
- **Клик по заголовку ячейки/термина** → input прямо в шапке.
- **Enter** — подтвердить. **Esc** — отменить.
- **Blur** — сохранить.

### 10.3. Редакторы блоков

- **`p` / `h3` / `quote`** — `contentEditable` + rich-панель над блоком.
- **`ul`** — редактор списка (стиль, уровни 0–2, Enter/Tab, paste многострочного).
- **`link`** — поля текст + URL с подсказкой.
- **`image` / `video`** — превью + кнопка **«✎ Изменить»** → раскрывается редактор медиа (src, загрузка файла, drag&drop, Ctrl+V, прогресс).
- **`table`** — сетка до 10×10, toggle заголовка, добавление/удаление строк/столбцов, вставка из Excel.

### 10.4. Rich-панель

B / I / U / S / ⯇≡⯈☰ / 🔗 / 💬. Использует `document.execCommand`.

### 10.5. Wiki-автокомплит

- Набрать `[[` → попап.
- Кнопка 🔗 / Ctrl+K.
- ↑↓ / Enter / Tab / Esc.
- Вставка `[[id]]`.

### 10.6. Примечания к тексту

- Выделить фрагмент → 💬 → модалка → сохранить.
- Маркер `((N))` появляется в тексте как синий кружок.

## 13. Известные ограничения

1. **`courseKey`** — если нет, fallback `default`.
2. **Тема общая** для всех курсов на домене (кроме агрегатора).
3. **`document.execCommand`** — устаревший API, но работает во всех браузерах.
4. **Объединённые ячейки** (`colspan`/`rowspan`) не поддерживаются.
5. **Дублирование кода** — некоторые утилиты дублируются между `reader.js` и `shared.js` (местами).

7. **`courses.bat`** не обновляет корневой `index.html`, `courses.js`, `server.js`.
8. **`localStorage` 5 МБ** — реально используется ~100 КБ.
9. **Медиа не встраивается в `data.js`** — только пути.
10. **GitHub Pages** — нужен VPN.
11. **Сервер** — только локальная сеть.
12. **Ctrl+V для видео** не работает.
13. **Ctrl+D** не работает, если фокус в поле ввода.
14. **Маркеры на картинке и текстовые примечания** — независимы.
15. **Лайтбокс** — только двойной клик / двойной тап.
16. **`<div>` внутри `<p>`** — невалидный HTML. Не делать.
17. **`courses.html` удалён.** Единая точка входа — `index.html` в корне.
18. **Drag&drop слайдов, ячеек, терминов** — только через ⋮ меню (↑↓). **Ручки ⠿ у них нет** (в отличие от блоков курса и блоков контента).

## 15. Если что-то сломалось

1. **F12 → Console** — первая красная ошибка.
2. **`Unexpected token '<'`** — маркер Git-конфликта в CSS/JS.
3. **`Illegal return statement`** — лишняя `}` выше.
4. **`Cannot access 'X' before initialization`** — TDZ: `let X` объявлена ниже того места, где используется. **Порядок блоков:** `let`-заглушки → `window.X = X` → автостарт.
5. **`Identifier 'X' has already been declared`** — дубль `let X` в одной области.
6. **`Unexpected token 'function'`** — пропущена `}` в предыдущей функции.
7. **`Unexpected token ')'`** — лишняя `)` (часто от `});`).
8. **404 на шрифты** — папка `fonts/` не залита.
9. **Плашка не появляется** — проверь `.status.show`.
10. **«Сохранить» не работает** — сервер запущен? Открыто через `http://localhost:3000/...`?
11. **Порт 3000 занят** — закрой старое окно (`Ctrl+C`) или `taskkill /IM node.exe /F`.
12. **`currentMode is not defined`** в Console — нормально, переменная внутри IIFE.
13. **Автосохранение не работает** — сервер запущен? Открыто через `http://`, не `file://`?
14. **Батник падает на `[3]` с `. was unexpected at this time`** — внутри `(...)` блоков `%CD%` или переменная с точкой. **Вынести в `goto`-метки.**
15. **Кракозябры в батнике** — пересохранить в **UTF-8 without BOM**.
16. **Файлы в курсе не обновились** — `courses.bat` [2] **не сработал**? Копируй `_source/*` вручную.
17. **Кнопка ⋮ не появляется** — проверь: в `author-mode`? CSS `.cell-menu-btn` есть? `data-memo-menu-idx` в DOM?
