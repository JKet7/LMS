# Техническая документация проекта «Конструктор курсов»

## 1. Обзор

Проект — **конструктор учебных курсов** на чистом HTML/CSS/JS + **локальный Node-сервер**. Без фреймворков, без сборки, без облака.

Три части:

1. **Агрегатор** (`index.html` в корне + `courses.js`) — страница со списком курсов.
2. **Редактор** (`admin.html` + `admin.css` + `admin.js`) — наполнение курса.
3. **Плеер** (`index.html` + `index.css` + `index.js`) — просмотр курса учеником.

Данные курса — в `data.js` внутри папки курса. Сборка и тиражирование — через `courses.bat`. Сервер — `server.js` (Node.js). Прогресс и тема — в `localStorage`.

> **Важно:** с недавних пор **единая точка входа — `index.html`**. Файл `courses.html` **удалён**, чтобы не было дублей. GitHub Pages и локальный сервер теперь отдают `index.html`.

## 3. Сборка и тиражирование (`courses.bat`)

| Пункт | Действие |
|---|---|
| **[1] Создать новый курс** | Копирует из `_source` 6 файлов, `fonts/`, создаёт `images/` и `videos/`, генерирует `data.js` с `courseKey`. |
| **[2] Обновить ВСЕ курсы** | Перезаписывает 6 файлов во всех папках с `data.js` (кроме `_source`). **`data.js`, медиа, шрифты не трогает.** |
| **[3] Запустить сервер** | Проверяет Node, `server.js`, `index.html`, запускает `node server.js`, открывает `http://localhost:3000/index.html`. |
| **[4] Выход** | — |

**Список тиражируемых файлов** (`COURSE_FILES`): `admin.html admin.css admin.js index.html index.css index.js`.

**Не тиражируются:** `index.html` в корне, `courses.js`, `colorsD.html`, `colorsJ.html`, `server.js`, `data.js`.

**Особенности:**
- **[1] Валидирует имя курса.** Разрешены только `a-z A-Z 0-9 _ -`. Пробелы, кириллица, спецсимволы — отклоняются с ошибкой.
- **[3] Проверяет наличие `server.js` и `index.html`** до запуска. Если нет — сообщение и выход.
- **[1] [2] Все проверки — через метки (`goto`), не через `(...)` блоки.** Это **важно**: `cmd` не умеет парсить `%CD%` внутри `(...)`, если значение содержит точку в конце (типа `C:\Users\vrop\Desktop\КУРСЫ.`) — `. was unexpected at this time.` и батник падает. **Не менять этот паттерн.**
- **Кодировка `courses.bat`** — должна быть **UTF-8 without BOM**. С BOM батник падает на первой строке.

## 4. Локальный сервер (`server.js`)

Node-сервер на порту **3000**, слушает `0.0.0.0` (доступен с телефона в той же Wi-Fi).

### 4.1. Раздача статики

Отдаёт файлы из `ROOT` (папка `server.js`). `/` → **`index.html`**. `Cache-Control: no-cache`.

### 4.2. Сохранение — `POST /save-data`

- Принимает тело (готовый `data.js`).
- Определяет папку курса из `Referer` (`/Test/admin.html` → `Test`).
- Пишет в `ROOT/Test/data.js`.
- **Валидация:** тело должно содержать `const courseSettings` и `const allLessons`. Иначе — 400.
- Отвечает `200 ok`.
- Лимит тела — 50 МБ.
- Запись — **асинхронная** (`fs.promises.writeFile`), не блокирует event loop.

### 4.3. Загрузка медиа — `POST /upload?course=Test&type=images&filename=foo.png`

- Сохраняет в `ROOT/Test/images/foo.png` (или `videos/`).
- При совпадении имени — добавляет `_1`, `_2`, … (до 1000).
- Возвращает `{ path: "images/foo.png", size: 12345 }`.
- Имя санитизируется: `[^a-zA-Zа-яА-Я0-9._\-\s]` → `_`.
- **Белый список расширений:** `.png .jpg .jpeg .gif .webp .svg .mp4 .webm .ogg`. Остальные — 400.
- Лимит файла — 200 МБ.

### 4.4. Проверка — `GET /ping` → `pong`.

### 4.5. Особенности

- `safeJoin` с `.normalize("NFC")` — корректная работа с кириллицей в путях.
- **`safeJoin` защищает от выхода за ROOT** через проверку `b === a || b.startsWith(a + path.sep)`. Без `path.sep` был бы баг: `"C:\A\BC".startsWith("C:\A")` === `true`, хотя папка лежит рядом.
- `decodeURIComponent` в GET обёрнут в `try/catch` (битый URL → 400, не падение).
- Диагностика на старте: `ROOT`, наличие `index.html`, IP-адреса для телефона.
- Логи: `✓ Сохранено: Test/data.js (37491 байт)`, `✓ Загружено: Test/images/foo.png`.
- При `EADDRINUSE` — подсказка поменять `PORT` на 3001/8080.

## 5. Формат данных (`data.js`)

```js
const courseSettings = {
    "courseKey": "english",
    "pageTitle": "Английский",
    "courseTitle": "Английский: Артикли"
};

const allLessons = {
    "new_lesson": { /* блок 1 */ },
    "new_quiz":   { /* блок 2 */ }
};
```

`courseKey` — для ключей в `localStorage`. Нет ключа → `"default"`.

### 5.1. Типы блоков (`lesson.type`)

| Тип | Структура |
|---|---|
| `theory` | `{ title, slides: [{ shortName, title, content: [...] }] }` |
| `quiz` | `{ title, groups: [], randomizeQuestions, randomizeOptions, questions: [...] }` |
| `memo` | `{ title, cells: [{ title, content: [...] }] }` (макс. 8) |
| `glossary` | `{ title, terms: [{ name, content: [...] }] }` |

### 5.2. Блоки контента (внутри `content[]`)

| Тип | Структура |
|---|---|
| `p` | `{ type: "p", text, notes? }` — может содержать `<b>`, `<i>`, `<u>`, `<s>`, `<br>`, `style="text-align:..."`, `[[wiki-ссылки]]` и `((N))` примечания. `notes` — массив строк примечаний. |
| `h3` | `{ type: "h3", text, notes? }` — то же |
| `quote` | `{ type: "quote", text, notes? }` — то же |
| `ul` | `{ type: "ul", style: "bullet"\|"number"\|"checkbox", items: [{ text, level: 0\|1\|2 }] }` |
| `link` | `{ type: "link", text, href }` — внутренние `#ключ_блока:слайд` или внешние |
| `image` | `{ type: "image", src, alt, markers? }` — `markers` — массив точек с примечаниями |
| `video` | `{ type: "video", src }` |
| `table` | `{ type: "table", header: bool, rows: [[...]] }` — макс. 10×10 |

### 5.3. Типы вопросов

| Тип | Структура |
|---|---|
| `single` | `{ type, text, options: [], correct: [1], explain, group }` |
| `multi` | `{ type, text, options: [], correct: [N], explain, group }` |
| `match` | `{ type, text, pairs: [{ left, right }], explain, group }` |
| `card` | `{ type, front, frontImage, back, backImage, group }` |

### 5.4. Wiki-ссылки и примечания в тексте

**Wiki-ссылки** — внутренние ссылки между блоками:

| Формат | Что делает |
|---|---|
| `[[ключ]]` | Ссылка на блок. Текст — `lesson.title`. |
| `[[ключ:3]]` | Ссылка на блок + слайд/ячейку/термин №3 (нумерация с 1). |
| `[[ключ\|текст]]` | Ссылка на блок с кастомным текстом. |
| `[[ключ:3\|текст]]` | Комбинация: слайд + кастомный текст. |

В плеере — `<a class="wiki-link wiki-link-<type>">`. В админке — автокомплит (см. 8.12). **Backlinks** — автоматически собираются по всем блокам, показываются под слайдом/ячейкой/термином/тестом как «↩ Упоминается в». Если блока нет — `<span class="wiki-link-broken">`.

**Примечания в тексте** — пояснения к фрагменту текста, привязанные к **блоку**:

| Формат | Что делает |
|---|---|
| `((1))`, `((2))`, … | Маркер примечания. Номер — индекс в массиве `notes` (нумерация с 1). |

Хранится в **том же блоке контента**, где встречается маркер:

```js
{
    "type": "p",
    "text": "Термин ((1)) встречается в статье ((2)).",
    "notes": [
        "Определение термина — см. в глоссарии.",
        "Имеется в виду статья 15 Конституции."
    ]
}
```

- Один блок может иметь **несколько** примечаний.
- Один и тот же текст примечания переиспользуется: если `notes[i]` уже есть — присваивается его номер.
- Если `((N))` удалили из текста вручную, примечание **остаётся в `notes`** — помечается как «удалено из текста».
- Если в `notes` нет нужного индекса — маркер рендерится как `.note-broken`.

### 5.5. Маркеры на картинке

В `image`-блоке может быть массив `markers`:

```js
{
    "type": "image",
    "src": "images/cleaner.png",
    "alt": "",
    "markers": [
        { "x": 42.5, "y": 18.3, "text": "Всасывающий шланг..." },
        { "x": 55.0, "y": 30.0, "text": "Ручка с кнопкой разбрызгивания." }
    ]
}
```

- `x`, `y` — в **процентах** от ширины/высоты картинки.
- `text` — примечание, всплывающее при клике.
- Маркеры **независимы** от текстовых `((N))`.

## 7. Агрегатор (`index.html` в корне + `courses.js`)

`courses.js` — единственный файл, который автор правит вручную:

```js
const COURSES = [
    { folder: "english", title: "Английский: Артикли" }
];
```

Читает `COURSES`, рендерит сетку карточек (4/3/2/1 колонки). Ссылка на `folder/index.html`.

Защита: `safeFolderName` + `escapeHtml`. Тема — `kp_aggregator_theme`.

**Особенности:**
- **Anti-FOUC** — тема применяется до отрисовки (скрипт в `<head>`).
- **`<meta name="viewport">`** — есть, работает на телефоне.
- **`<meta name="color-scheme" content="light dark">`** — есть.
- **`<noscript>`** — если JS отключён, показывается сообщение.
- **`<meta name="description">`** — есть.

**Что было:** раньше в корне было **два файла** — `courses.html` (агрегатор) и `index.html` (дубль для GitHub Pages). **Теперь `courses.html` удалён**, всё завязано на `index.html`.

## 8. Редактор (`admin.html` + `admin.js` + `admin.css`)

### 8.1. Поток

1. `admin.html` → `data.js` → `admin.js`.
2. Проверка `courseSettings` и `allLessons`.
3. Миграции (старые списки → `{text, level}`, `slide.video/image` → блоки, `image.markers` → `[]`).
4. Загрузка черновика из `localStorage`.
5. `init()` → `refreshAll()`.

### 8.2. Синхронизация

- **Из данных в DOM:** `renderSlide`, `renderCell`, `renderQuizEditor`, `renderTableGrid`.
- **Из DOM в данные:** `readFromDom()`.
- Поля — `oninput="onFieldChange()"` (debounce **2 секунды**).
- **`contentEditable`-блоки** (`p`, `h3`, `quote`) читаются через `readEditableBlocks()` → `extractNoteMarkers()`.

### 8.3. Rich-панель

Над `p` / `h3` / `quote`:

- **B / I / U / S** — жирный, курсив, подчёркнутый, зачёркнутый.
- **⯇ ≡ ⯈ ☰** — выравнивание.
- **🔗** — вставить wiki-ссылку (см. 8.12).
- **💬** — добавить примечание к выделенному тексту (см. 8.13).

`document.execCommand`. **Enter** → `<br>`.

**Санация (`sanitizeHtml`):**
- **Удаляет HTML-комментарии** `<!-- ... -->` (артефакты Word/Google Docs).
- Удаляет `script`, `style`, `iframe`, `object`, `embed`, `svg`, `math`.
- Белый список тегов: `strong`, `b`, `em`, `i`, `u`, `s`, `strike`, `del`, `br`, `span`, `div`, `p`.
- Только `style="text-align:..."` — остальные атрибуты (включая `onclick`) отрезаются.

### 8.4. Редактор списка

- Стиль: `bullet` / `number` / `checkbox`.
- Уровни 0–2.
- **Enter** — новый пункт.
- **Tab / Shift+Tab** — уровень.
- Кнопки ⇤ ⇥ ＋ ✕.
- Копипаст многострочного — каждая строка = пункт.

### 8.5. Редактор таблицы

- **Выделение:** клик, Shift+клик, drag, Shift+стрелки, Ctrl+A, Esc.
- **Delete / Backspace** — очистка выделенного.
- **Ctrl+V** из Excel/Sheets — HTML-таблица или TSV.
- **Ctrl+C** — копирование диапазона как HTML+TSV.
- Кнопки «📥 Вставить из буфера» / «📤 Скопировать выделенное».
- Лимит 10×10.

### 8.6. Редактор медиа

Для `image` и `video`:

- **Кнопка «📁 Выбрать файл»**.
- **Drag&drop** на зону.
- **Ctrl+V** — для картинок.
- **Прогресс-бар**.
- **Имя** — через `prompt()`.
- **Форматы:** PNG/JPEG/GIF/WebP/SVG; MP4/WebM/OGG.
- **Прямая ссылка** — работает.
- **Без сервера** — сообщение «⚠ Сервер не запущен».

### 8.7. Дублирование

**Блок** — кнопка 📋 в списке блоков. Копия `<id>_copy`, название `<название> (копия)`, вставляется после оригинала.

**Слайд / ячейка / термин** — кнопка «📋 Дублировать» внизу сайдбара + **Ctrl+D**.

### 8.8. Автосохранение

**Каждое изменение** → через **2 секунды** → `POST /save-data` → `data.js` на диске.

- При успехе — **тихо**, `localStorage` черновик удаляется.
- При ошибке сервера — тихо в консоль, черновик остаётся.
- Кнопка «💾 Сохранить» — принудительно.
- Без сервера — только черновик + ручное «📤 Скачать».
- **Защита от гонок:** `autoSaveInFlight` / `autoSavePending`.
- **Таймаут запроса:** 15 сек (`fetchWithTimeout` с `AbortController`).

### 8.9. Статусная плашка (`setStatus`)

- **Fixed внизу по центру экрана**, поверх всего.
- Появляется fade+slide, исчезает через **6 секунд**.
- Цвет: `ok` (зелёный), `err` (красный), без типа (жёлтый).
- **Обязательно:** `.status.show { display: block; opacity: 1; ... }`.

### 8.10. Глоссарий — импорт/экспорт CSV

**Экспорт** — кнопка 📤 Экспорт CSV в сайдбаре блока глоссария.

- Формат: `Термин;"Содержимое"`, разделитель `;`, UTF-8 с BOM.
- Содержимое склеивается из блоков (`p`, `h3`, `ul`, `quote`, `link`) через `\n`.
- **Примечания `((N))`** — превращаются в `[текст примечания]` (через `stripNoteMarkers`).
- Картинки/видео игнорируются.

**Импорт** — кнопка 📥 Импорт CSV.

- Читает CSV (UTF-8 / cp1251), определяет заголовок.
- Спрашивает «Заменить / Добавить».
- Строки с `• ` превращаются в списки, `### ` — в `h3`, остальное — в `p`.

### 8.11. Импорт теста из CSV

Кнопки в блоке теста:

- **📥 Импорт из CSV** — три типа: `single_multi`, `match`, `card`, либо автоопределение.
- **📄 Скачать шаблоны CSV** — три шаблона.
- Двухшаговая проверка: сначала отчёт, потом «Заменить / Добавить».

### 8.12. Wiki-автокомплит

**Где:** в `p` / `h3` / `quote` (contentEditable-поля).

**Как вызвать:**
- Набрать `[[` — попап откроется автоматически.
- Кнопка **🔗** в rich-панели.
- **Ctrl+K**.

**Что показывает:** список блоков с иконкой типа (📄 Теория, 🧪 Тест, 📌 Памятка, 📖 Глоссарий), отфильтрованный по введённому запросу.

**Управление:** ↑ / ↓ — выбор. **Enter / Tab** — вставить. **Esc** — закрыть. **Клик мышью** — вставить.

**Что вставляет:** `[[id]]` (без номера слайда).

**Особенности реализации:**
- `replaceWikiTrigger` вызывает `editable.normalize()` — склеивает соседние текстовые ноды.
- `isPickingFromPopup` — флаг, чтобы `blur` не закрыл попап раньше времени.
- `insertWikiLinkAtCaret` не плодит `[[`, если каретка уже внутри незакрытой `[[`.
- `ignoreNextInput` — чтобы программная вставка не триггерила повторный поиск.

### 8.13. Примечания к тексту — UI в админке

**Добавление:**
1. Выделить фрагмент текста в `p` / `h3` / `quote`.
2. Нажать **💬** в rich-панели.
3. В модалке ввести текст примечания.
4. **OK** → в текст вставляется `((N))`, рендерится как **синий маркер**.
5. Под блоком появляется **список примечаний**.

**Список под блоком:**
- Номер в синем кружке + текст.
- **✎** — открыть модалку редактирования.
- **✕** — удалить примечание.
- Если `((N))` удалили из текста вручную — примечание помечается серым с плашкой **«удалено из текста»**.

**Клик по подсвеченному маркеру в тексте** — открывает **модалку редактирования**:
- Поле `textarea` с текущим текстом.
- Кнопки **🗑 Удалить / Отмена / Сохранить**.
- Ниже — **список всех примечаний этого блока**.
- **Esc** — закрыть. **Ctrl+Enter** — сохранить.

## 9. Плеер (`index.html` + `index.js` + `index.css`)

### 9.1. Экраны

- `#screen-menu` — список блоков
- `#screen-lesson` — теория
- `#screen-quiz` — тест
- `#screen-memo` — памятка
- `#screen-glossary` — глоссарий

### 9.2. Адаптивная ширина

`showScreen(name)`:

- `memo` → `.wide` (`min(1800px, 96vw)`)
- `quiz` → `.narrow` (`min(1000px, 92vw)`)
- остальные → `min(1400px, 95vw)`

### 9.3. Теория

- `renderSlide()` — слайд + навигация.
- `renderContentBlocks()` — блоки:
  - `p` → `<div class="text-p">` (не `<p>`, чтобы внутри мог быть `<div>` с `text-align`);
  - `h3` → `<h3>`;
  - `quote` → `<div class="quote">`;
  - `image` → `renderImageBlock(b)` (с маркерами и лайтбоксом);
  - `video` → `<video>` + `<div class="print-video-placeholder">`;
  - `table` → `renderTable(b)`.
- Прогресс: `markVisited`, `updateProgressBar`, `renderTopicList`.

### 9.4. Безопасный рендер текста

**`renderSafeText(text, opts)`** — экранирует HTML, но **разрешает** базовые теги и сохраняет wiki-ссылки.

**Что делает:**
1. **Удаляет HTML-комментарии** `<!-- ... -->` (артефакты Word).
2. **Экранирует** `&`, `<`, `>`, `"`, `'`.
3. **Восстанавливает** разрешённые теги по белому списку: `b`, `i`, `u`, `s`, `strong`, `em`, `br`, `strike`, `del`, `div`, `span`, `p`.
4. **Восстанавливает** `style="text-align: left|center|right|justify"` — только выравнивание.
5. **Пропускает через `renderWikiLinks`** (если `opts.allowWiki !== false`).

**Ключевая регулярка:** `/&lt;(\/?)([a-zA-Z][a-zA-Z0-9]*)\b([\s\S]*?)&gt;/g`

> **Важно:** `[\s\S]*?` — а не `[^&]*?`. Второй **ломается** на атрибутах с `&` (после экранирования `"` → `&quot;`), и теги **не восстанавливаются**.

### 9.5. Wiki-ссылки в плеере

`renderWikiLinks(html)` — находит `[[...]]` и превращает в `<a class="wiki-link wiki-link-<type>">`.

- Тип блока определяет цвет: `theory` → бордовый, `quiz` → зелёный, `memo` / `glossary` → синий.
- Битые ссылки — `<span class="wiki-link-broken">`.
- **Backlinks** — `buildBacklinksIndex()` один раз при первом рендере, потом `renderBacklinks(targetLessonId)` показывает «↩ Упоминается в».

### 9.6. Примечания в тексте — поведение

`renderNotes(html, notes)` — превращает `((N))` в:

```html
<span class="note" data-note-idx="N-1" data-note-text="текст">N</span>
```

- **Наведение мышью** → **карточка** (`.note-card`) рядом со словом.
- **Клик / тап** → карточка появляется / скрывается.
- **Esc / клик мимо / скролл** → карточка скрывается.
- Если `((N))` без парного `notes[N-1]` — рендерится как `.note-broken`.

### 9.7. Маркеры на картинке — поведение

`renderImageBlock(b)` — если в блоке есть `markers`, картинка оборачивается в `.img-with-markers`, и поверх неё рисуются:

```html
<button class="img-marker" data-marker-idx="0" style="left:X%;top:Y%;"></button>
```

- **Клик / тап по маркеру:**
  - на десктопе → **карточка** рядом с маркером;
  - на мобильном (`isTouchDevice()` или `window.innerWidth < 700`) → **модалка** (`.img-marker-modal-overlay`).
- **Esc / клик мимо** — закрыть.

### 9.8. Лайтбокс

- **Двойной клик** по картинке (десктоп) → открывается `.lightbox-overlay` с увеличенным изображением.
- **Двойной тап** (мобильный, < 350 мс между касаниями) → то же.
- Закрытие: **Esc**, клик по фону, клик по крестику, клик по самой картинке.
- `data-lightbox="1"` — атрибут на всех `<img>` в контенте.

### 9.9. Бесшовный переход между модулями

**`getNextLessonId(currentId)`** — следующий `id` из `allLessons` или `null`.

**`goToNextLesson()`** — помечает текущий блок `completed`, открывает следующий:
- тест → **сразу стартует**,
- памятка / глоссарий → **открывается**,
- теория → **первый слайд**.

**Кнопки:**

| Где | Кнопки |
|---|---|
| Последний слайд теории | «Завершить блок» + «<Название> →» |
| Финальный экран теста | «Пройти заново» + «Завершить блок» + «<Название> →» |
| Памятка | «Завершить блок» + «<Название> →» |
| Глоссарий | «Завершить блок» + «<Название> →» |
| **Последний модуль курса** | «Завершить блок» + «← В меню» |

**Стили:** `.nav-row-right`, `.memo-nav-row`, `.glossary-nav-row`.

### 9.10. Тест

- `startQuiz(id)` — фиксация порядка + **пересборка `_questionsOrder` / `_optionsOrder` / `_matchOrder`**.
- `renderQuiz()` — текущий вопрос.
- Ответы: `quizAnswer` / `quizCheckMulti` / `checkMatchPair` / `cardAnswer`.
- Навигация: `quizGoNext/Prev/To`.
- Финал: `renderQuizResult()` + статистика по группам.
- **Оценка** — с первой попытки.
- **Таймер** — сохранение каждые 10 сек.
- **Рандомизация** — в `_questionsOrder`, `_optionsOrder`, `_matchOrder`.

### 9.11. Памятка

`renderMemo()` → сетка `.memo-grid` с колонками 1–4 + навигация `.memo-nav-row` + backlinks после сетки.

### 9.12. Глоссарий

Сортировка по имени, буквенные разделители, поиск с подсветкой `<mark>` + навигация `.glossary-nav-row`.

**Экспорт CSV** — кнопка **📊** в топбаре. Формат: `Термин;"Содержимое"`, `;`, UTF-8 BOM. Примечания `((N))` → `[текст]`.

### 9.13. PDF (печать)

`printCurrent()`:

- **теория / памятка** — `prepareNotesForPrint()` → `window.print()` → `cleanupPrintNotes()`.
- **тест** — подменяет содержимое на `renderQuizForPrint`.
- **глоссарий** — подменяет содержимое на `renderGlossaryForPrint`, скрывает сайдбар.

**`prepareNotesForPrint()`** — под каждым `p` / `h3` / `.quote` с примечаниями и под каждой картинкой с маркерами добавляет `.print-notes` — список «1. ..., 2. ...». В самом тексте маркеры печатаются как `[N]`.

**`cleanupPrintNotes()`** — удаляет все `.print-notes` после печати.

### 9.14. Обработка ошибок медиа

На каждом рендере — `error`-хендлеры → `.slide-media-error` («⚠ Файл не найден: `<code>src</code>`»).

### 10.4. Псевдо-абзац `.text-p`

Блоки типа `p` в плеере рендерятся как `<div class="text-p">` (а не `<p>`). Стили:

- **В слайде:** `.slide-content .text-p` — те же, что у `p`.
- **В памятке:** `.memo-cell-body .text-p` — те же, что у `p` в ячейке.

Это нужно, чтобы внутри абзаца можно было **разместить `<div style="text-align:center">`** — `<div>` внутри `<p>` **невалиден** и выкидывается браузером.

## 12. Соглашения

### Для автора

1. Не править `data.js` вручную — только через `admin.html`.
2. Не менять `courseKey`.
3. Не переименовывать папку курса.
4. Пути — без ведущего слэша: `images/foo.png`.
5. Файлы — в `images/` и `videos/`.
6. После добавления курса — строка в `courses.js`.
7. Wiki-ссылки — через 🔗 / `[[` / Ctrl+K, **не** набирать `]]` вручную.
8. Примечания — через 💬 или через маркеры на картинке, **не** набирать `((N))` вручную.
9. **Не использовать `<div>` внутри `<p>`.** Если нужно центрировать — используй `style="text-align:center"` **на самом `<p>`**, а не оборачивай в `<div>`.

### Для разработчика

1. Правки кода — в `_source/`.
2. После — `courses.bat` → [2].
3. `admin.css` и `index.css` — синхронны по переменным.
4. `data.js` — источник истины для плеера.
5. Новый тип блока → четыре места: `index.js`, `admin.js` (createBlockElement + preview), `admin.html` (кнопки), `index.css` + `admin.css` (стили).
6. **Следить за маркерами Git-конфликтов (`<<<<<<<`).** Если видишь их в CSS — браузер игнорирует всё после `=======` до `>>>>>>>`.
7. Сервер запускать перед работой.
8. **В `courses.bat` не использовать `%VAR%` внутри `(...)` блоков**, если значение содержит `.` или `)`. **Только `goto`-метки.** Иначе — `. was unexpected at this time.`
9. **`courses.bat` — UTF-8 without BOM.** С BOM — падает.
10. **`renderSafeText` — регулярка `[\s\S]*?`**, а не `[^&]*?`. Иначе теги с атрибутами не восстанавливаются.

## 13. Известные ограничения

1. **`courseKey`** — если нет, fallback `default`. Может привести к смешению прогресса между курсами.
2. **Тема общая** для всех курсов на домене (кроме агрегатора).
3. **`document.execCommand`** — устаревший API. **Не трогаем.** Работает во всех браузерах.
4. **Объединённые ячейки** (`colspan`/`rowspan`) не поддерживаются.
5. **Стили из Excel** при вставке таблицы теряются.
6. **Дублирование кода рендера** между `index.js` и `admin.js`.
7. **Нет версионирования** `data.js`.
8. **`courses.bat`** не обновляет корневой `index.html`, `courses.js`, `server.js`.
9. **`localStorage` 5 МБ** — реально используется ~100 КБ, запас 50×.
10. **Медиа не встраивается в `data.js`** — только пути.
11. **GitHub Pages** — нужен VPN.
12. **Сервер** — только локальная сеть.
13. **Ctrl+V для видео** не работает (браузеры не кладут видео в буфер).
14. **`Ctrl+D`** не работает, если фокус в поле ввода (это by design).
15. **Предпросмотр в админке** — wiki-ссылки и кнопки **не работают**, это ожидаемо.
16. **Текстовые примечания `((N))`** не удаляются автоматически при удалении маркера из текста — остаются в `notes` и помечаются как «удалено из текста» (это by design).
17. **При ручном вводе `((N))`** без соответствующего индекса в `notes` — маркер рендерится как `.note-broken`.
18. **Маркеры на картинке и текстовые примечания** независимы — разные массивы (`markers` vs `notes`).
19. **Лайтбокс** работает только по `dblclick` / двойному тапу — обычный клик не увеличивает.
20. **`<div>` внутри `<p>`** — невалидный HTML. Если в данных такое есть — браузер выкинет `<div>` из `<p>`. **Не делать так.** Использовать `style="text-align:center"` на самом `<p>`.
21. **`<!--StartFragment-->` / `<!--EndFragment-->`** — артефакты Word. Раньше **сохранялись** в `data.js`, потому что `sanitizeHtml` их не трогала. **Теперь — удаляются** при сохранении. **Существующие данные** — почищены через `clean-data.js` (одноразовый скрипт, удалён).
22. **`courses.html` удалён.** Единая точка входа — `index.html` в корне.
23. **`clean-data.js`** — одноразовый скрипт массовой чистки `data.js`. **Удалён** после прогона. Если понадобится — восстановить можно.

## 15. Если что-то сломалось

1. **F12 → Console** — первая красная ошибка.
2. **`Unexpected token '<'`** — маркер Git-конфликта в CSS/JS.
3. **`Illegal return statement`** — лишняя `}` выше закрыла функцию раньше времени.
4. **`missing ) after argument list`** — незакрытый template literal (`` ` ``), чаще всего в `createMediaBlock` / `renderImageBlock`.
5. **404 на шрифты** — папка `fonts/` не залита.
6. **На ПК работает, на телефоне нет** — кеш, VPN, встроенный браузер.
7. **Чёрный экран** — тема применилась, но JS упал.
8. **Плашка не появляется** — проверь `.status.show { display: block }`.
9. **«Сохранить» не работает** — сервер запущен? Админка через `http://localhost:3000/...`?
10. **`Порт 3000 занят`** — закрой старое окно сервера (Ctrl+C) или `taskkill /IM node.exe /F`.
11. **Кнопка «Следующий модуль» не появляется** — проверь `.nav-row-right` в `index.css` и `goToNextLesson` / `getNextLessonId` в `index.js`.
12. **Глоссарий: кнопок 📄/📊 нет** — проверь `#screen-glossary` в `index.html`.
13. **Автосохранение не работает** — сервер запущен? Открыто через `http://localhost:3000/...`, а не `file://`?
14. **Wiki-ссылка не вставляется** — страница открыта через `http://localhost:3000/...`? Через `file://` `Range`/`Selection` могут вести себя иначе.
15. **`]]]]` после вставки wiki-ссылки** — был баг в `replaceWikiTrigger`. Починено: `editable.normalize()` + `isPickingFromPopup`.
16. **Примечание не появляется в тексте** — проверь, что `admin.js` обновлён до версии с `renderNotesInText`, `extractNoteMarkers`, `openNoteEditor`, `openNoteEditModal`.
17. **`((1))` виден как текст в админке** — это ожидаемо, если блок **не перерисован**. Сохрани / переключи блок — станет синим маркером.
18. **Карточка примечания не появляется в плеере** — проверь `renderNotes` в `index.js` и `.note` / `.note-card` в `index.css`.
19. **Маркер на картинке не появляется** — проверь `renderImageBlock` в `index.js` и `markers` в `data.js`.
20. **Лайтбокс не открывается** — на `<img>` должен быть `data-lightbox="1"`.
21. **В предпросмотре админки `((N))` видны как текст** — это by design.
22. **В PDF примечания не печатаются** — проверь `prepareNotesForPrint` / `cleanupPrintNotes` в `index.js`.
23. **`<!--StartFragment-->` виден в плеере** — не применён `renderSafeText` (или не применён в нужном месте). Проверь, что в `renderContentBlocks` для `p`/`h3`/`quote` **вызывается `renderSafeText`**, а не `renderWikiLinks`.
24. **`<div style="text-align:center">` виден как текст** — регулярка в `renderSafeText` **должна быть** `[\s\S]*?`, а не `[^&]*?`. Иначе теги с `style="..."` не восстанавливаются.
25. **Батник `courses.bat` падает на `[3]` с `. was unexpected at this time.`** — внутри `(...)` блоков используется `%CD%` (или другая переменная с точкой). **Вынести проверки в `goto`-метки.**
26. **`courses.bat` показывает кракозябры вместо русских букв** — файл сохранён в UTF-8 **with BOM**. Пересохранить в **UTF-8 without BOM**.
27. **`Окно закрывается при нажатии [3]`** — порт 3000 занят (старый `node.exe` не убит). `taskkill /IM node.exe /F`, потом запустить заново.
28. **`cd /d` не работает в cmd** — нужны **кавычки**, если путь содержит кириллицу: `cd /d "C:\Users\vrop\Desktop\КУРСЫ"`.
29. **GitHub Pages отдаёт не тот файл** — в корне должен быть **только `index.html`**, `courses.html` удалён.
30. **`node clean-data.js` — `Cannot find module`** — скрипт не в той папке. Убедись, что он **в корне проекта**, и что ты **в этой папке** через `cd /d "..."`.
